## 项目介绍

BOJI 是一个给瘦子新手的增肌入门网站：不需要注册、不需要装 App，浏览器打开就是一个完整的 16 周训练计划。所有训练/饮食内容、打卡数据都保存在你自己的浏览器里，没有任何后端和网络请求。

## ✨ 功能

| 模块 | 说明 |
| --- | --- |
| 🏠 **总览** | 体型档案（身高/体重/BMI/目标）、四阶段路线图、核心原则、瘦子 FAQ |
| 📅 **训练计划** | 16 周 · 每周 3 练 · 前 4 周每次 4 个动作，之后最多 5 个动作；重复练熟基础模式，不用复杂分化和高级技巧 |
| 🏋️ **动作库** | 置顶「三大基础动作」专区（俯卧撑 / 深蹲 / 仰卧起坐）：默认嵌入 B 站视频讲解，一键切换零依赖的内联 SVG 循环动图；下方 13 个计划必需动作，每个配独立示范图、要点、常见错误与替代方案，按部位筛选 |
| 🍚 **饮食** | 按 Mifflin-St Jeor 公式计算目标摄入，覆盖体重趋势、热量调整、蛋白质和训练前后饮食；手掌分量法、一周食谱轮换、食材互换表、外食生存指南（食堂/外卖/聚餐）、饮食误区 FAQ，食谱示例按目标热量智能换算，附补剂避坑 |
| 📈 **追踪** | 16 周训练打卡、完成率统计、目标体重差距、数据导出/导入（JSON） |

### 技术特点

- 纯静态 `HTML + CSS + 原生 JavaScript`，**无任何框架、无构建步骤、无网络请求**
- Apple 官网式极简设计语言：无边框卡片、灰白底色分层、单一蓝色主色
- 深色 / 浅色双主题：默认跟随系统，右上角按钮手动切换（选择会被记住）
- 数据全部存在浏览器 `localStorage`，不收集任何隐私；移动端优先、打印友好
- 所有训练/饮食内容集中在 [`js/data.js`](js/data.js)，改一个文件即可定制自己的计划

## 🚀 本地运行

不需要安装任何东西——直接双击打开 `index.html` 即可。如果想用本地服务器（可选）：`python -m http.server 8000` 或 `npx serve .`，然后访问 http://localhost:8000

## 🐙 部署到 GitHub Pages

- **方式一（推荐）**：推送到 `main` 分支即可——仓库自带的 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) 会**自动开启 Pages 并部署**，地址为 `https://<用户名>.github.io/<仓库名>/`。
- **方式二**：**Settings → Pages → Source** 选择 `main` 分支 `/ (root)`，保存即可，无需任何构建。

## 📋 计划总览（默认：183cm / 68kg）

| 阶段 | 周期 | 频率 | 分化 | 目标 |
| --- | --- | --- | --- | --- |
| 1 适应奠基期 | 第 1–4 周 | 3 练/周 | 全身 A/B | 掌握动作模式、建立习惯 |
| 2 基础巩固期 | 第 5–8 周 | 3 练/周 | 全身 A/B/C | 重复基础动作，学习双递进 |
| 3 力量积累期 | 第 9–12 周 | 3 练/周 | 上肢/下肢/全身 | 小步加重，第 12 周减量 |
| 4 习惯定型期 | 第 13–16 周 | 3 练/周 | 上肢/下肢/全身 | 独立执行并完成周期复盘 |

共 48 次训练；饮食按每日约 **+350 kcal 温和盈余**、蛋白质 **2g/kg** 设计，并根据每周平均体重每次只调整 150–200 kcal。

## 🛠️ 定制自己的计划

所有内容都是数据驱动，编辑 [`js/data.js`](js/data.js)：

```js
const PROFILE_DEFAULT = {
  gender: "male",
  age: 25,
  height: 183,   // 改成你的身高
  weight: 68,    // 改成你的体重
  activity: 1.55,
  target: 72,    // 目标体重
};
```

- `PHASES` / `DAY_TPL` / `WEEK_FOCUS`：阶段、训练日动作编排与每周焦点
- `EXERCISES` / `FEATURED_EXERCISES`：动作库与置顶动作
- `MEALS` / `WEEK_MEALS` / `TIPS` / `FAQS`：饮食内容与新手指南

页面顶部的「饮食」页也支持直接在网页上修改资料，实时重算热量。
